## PR #6 レビュー指摘の検証と修正

- Touch ID は本人確認の手段で、同期するかは保存先で決まる（Google の対応環境一覧）。「Touch ID など端末固定の鍵」を直した
- signCount は SHOULD で、実装しない認証器は常に 0（WebAuthn L3 §6.1.1）。`docs/03` の「端末固定の鍵は増える」を、仮想認証器での観察と仕様に分けて書き直した
- 表示名の保存は認証器の任意（§6.3.2、必須は userHandle）。「WebAuthn 仕様で保存」をやめ、1Password で保存されていた実機の観察を根拠にした
- RP ID と origin の照合はブラウザ（§5.1.3/§5.1.4）、認証器は RP ID で鍵を絞る（§6.3.3）。フィッシング行の役割を分けた
- 1Password のサーバー侵害・パスワード漏洩の行は公式説明で裏付けが取れたので、根拠を「推測」から公式ページに替えた。Yubico の「取り出せない」は公式に明記が見つからず推測のまま
- マルウェアの行は、同期の性質から言える前半と推測の後半に分けた。マジックリンクの攻撃経路は推測として書き直した
